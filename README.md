# Sprachlabor Duo

**Учебная студия немецкого языка A1–C1 для самостоятельных занятий и работы в паре.**

Проект объединяет языковую практику, подготовку к экзаменам и планирование поступления. Изначально студия создана для пары, которая готовится к магистратуре в Германии.

[Приложение](https://sprachlabor-duo-2028.ps-kolesnikova.chatgpt.site) · [Программа](#программа) · [Методика](#методика) · [Локальный запуск](#локальный-запуск)

## Программа

Общий маршрут A1–C1 организован вокруг практических задач. На начальных уровнях это знакомство, встречи и повседневные запросы. Далее добавляются дискуссии, учебная переписка, работа с источниками и академическая аргументация. Выбранный уровень определяет сложность заданий.

| Ветка | Темы | Пример задачи |
| --- | --- | --- |
| **Data & MedTech** | Аналитика данных, IT, машинное обучение и медицинские продукты | Представить дашборд, объяснить выбор метрики и защитить выводы по вымышленному набору данных. |
| **Sprache & Medien** | Лингвистика, медиа, журналистика, мозг и когнитивная психология | Провести интервью, проверить формулировку заголовка и кратко передать результаты исследования с оговорками. |

Темы веток дополняют общую практику по чтению, аудированию, письму и устной речи. В профессиональных сценариях используются вымышленные ситуации и данные.

## Что есть в студии

- **Маршрут и контрольные точки.** Учебные цели и ориентиры по уровням, недельный ритм, рабочая тетрадь и отслеживание требований магистратур.
- **Тренажёр.** Задания с выбором ответа, заполнением пропусков и коротким вводом. После проверки видны ключ и пояснение. Ошибки и пропуски можно разобрать и повторить.
- **Лексика.** Карточки с активным воспроизведением и интервальным повторением. Контекст и повторное употребление помогают проверить, можно ли применить фразу в новом задании.
- **Контроль.** Стартовая выборка и короткие варианты с таймером, разбивкой по навыкам и разбором после сдачи. Для подготовки к конкретному экзамену в библиотеке есть полноформатные материалы организаторов.
- **Парная работа.** Письменный ответ или тезисы для устного задания можно сохранить и по выбору отправить партнёрше. Обратная связь строится по учебной рубрике. Для оценки устной речи предусмотрена живая практика.
- **Прогресс.** История попыток, учёт учебного времени, журнал ошибок и игровые достижения за практику.

## Методика

Программа опирается на уровни и наблюдаемые речевые действия CEFR. В планировании использованы принципы программы Goethe-Institut *Deutsch Lehren Lernen* (DLL). Закрытые упражнения готовят к открытым задачам, где участницы обмениваются информацией, договариваются и передают смысл собеседнику. Тематические ветки поддерживают выбор материала по интересам. [CEFR Companion Volume](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors) · [Принципы Goethe DLL](https://www.goethe.de/de/spr/unt/dll/upr.html) · [DLL 4: Aufgaben, Übungen, Interaktion](https://www.goethe.de/resources/files/pdf211/dll4_schnupperkapitel.pdf)

Практический цикл начинается с воспроизведения изученного без подсказки. Затем участницы разбирают новый материал, выделяют полезную форму, тренируют её и применяют в речевой задаче. После обратной связи следует повтор на новом примере. Распределённая практика и корректирующая обратная связь опираются на исследования усвоения второго языка. Интервалы карточек и расписание занятий заданы проектом. [Kim и Webb, 2022](https://doi.org/10.1111/lang.12479) · [Lyster и Saito, 2010](https://doi.org/10.1017/S0272263109990520)

Для проверки готовности предлагаются два свежих полноформатных комплекта конкретного экзамена. Результаты сравниваются по каждому навыку с критериями организатора. Условия прохождения, число прослушиваний и допустимые материалы сверяются по выбранному формату. [Goethe-Zertifikate](https://www.goethe.de/ins/de/de/prf/exc.html) · [Digitaler TestDaF](https://www.testdaf.de/de/teilnehmende/der-digitale-testdaf/aufbau-des-digitalen-testdaf/) · [telc Deutsch C1 Hochschule](https://www.telc.net/sprachpruefungen/zertifikatspruefung/deutsch/telc-deutsch-c1-hochschule/)

### Статус учебных результатов

Встроенные баллы описывают выполнение конкретной подборки. Открытые ответы проверяются человеком по учебной рубрике, а официальный результат определяет организатор экзамена. Sprachlabor Duo — независимый учебный проект без официальной аккредитации или одобрения упомянутых организаций.

## Доступ к учебным записям

- Публичные задания и библиотека доступны без учётной записи. Гостевой прогресс хранится в браузере.
- После входа учебные записи синхронизируются с личным аккаунтом. Сервер определяет владельца записи по подтверждённой учётной записи.
- Для работы в паре используется код на одно присоединение. Автор выбирает, какими работами поделиться, и может закрыть доступ к ним.
- Репозиторий содержит исходный код и учебные материалы проекта. Личные работы и прогресс хранятся отдельно.

## Локальный запуск

Нужен Node.js 22.13 или новее. Выполните команды из корня проекта.

```sh
npm run install:ci
node scripts/fetch-study-assets.mjs
npm run dev
```

Команда подготовки скачивает аудио, маскотов и офлайн-материалы с опубликованного сайта. Откройте URL, который выводит сервер разработки. Для гостевого режима дополнительная настройка не требуется. Сборка выполняется командой `npm run build`. Команда `npm run start` запускает локальную проверку собранного Worker.

Для разработки функций синхронизации примените локальные миграции D1 после сборки. Указанная миграция создаёт текущую схему с нуля.

```sh
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_white_lila_cheney.sql
```

Интерфейс расположен в `app/`, учебные задания и программа — в `lib/`, статические материалы — в `public/`. Схема базы описана в `db/`, миграции хранятся в `drizzle/`. Приложение собрано на Vinext и использует Cloudflare D1 для сохранения учебных записей.

## English summary

Sprachlabor Duo is a German-learning studio for independent and paired study from A1 to C1. It combines guided practice, timed drills, spaced vocabulary review and optional peer feedback. The two thematic tracks cover Data & MedTech and Language & Media. Official exam preparation materials are linked separately from the project’s practice exercises.
